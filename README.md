# os2026lx

面向本校《操作系统》课程的实验指导作品，参赛方向为「操作系统实验教程与竞赛指导」。

> **当前状态：第一版完成阶段。** 本地验证并完成了lab1（4个子目）和lab2的实验包设计
> 仓库中的内容会随确认结果调整。

## 项目目标

基于本校《操作系统》课程已有的实验要求（进程管理、内存管理），
重新设计并实现一套可以独立使用的实验资源：

- **题目文档** —— 原理、任务说明、分步实现指导、常见错误排查
- **起点代码** —— 学生拿到就能编译运行的框架，关键处留待实现
- **测例** —— 自动判定，失败时给出可读的错误信息
- **参考实现** —— 卡住时可对照的完整答案
- **兼容性** —— 使用 Windows（包含虚拟机方案）以及 Mac 设备都受支持。其中，因为 Mac 设备有一些函数/功能的调用和 Windows 不一样，故特别对 Mac 版本做了适配性修改，带有 `XXXforMacOS`的实验包即为 Mac 设备使用。

## 开发约定

- 每个实验一个分支，完成后合入 `main`
- 一个实现步骤对应一次提交，保留完整的开发与修复过程
- `main` 分支始终保持可构建、可运行
